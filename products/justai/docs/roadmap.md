# Roadmap and Gates

## v1: contracts and public static release

State slices: `justai-observatory-contracts-v1`, `justai-public-observatory-v1`, `justai-federation-charter-v1`, and `justai-evidence-bridge-v1`.

Complete the signed release contract, cross-language fixtures, bounded source intake, deterministic renderer, charter, evidence policy, public source register, and the metadata-only open/restricted evidence bridge.

Acceptance requires a clean-checkout validator, valid signatures, reproducible rendering, explicit uncertainty and contestation, no secret or personal-data leakage, and no model or third-party network authority.

## Later gated work

Protected intake (`justai-protected-intake-v1`) requires legal, privacy, external security, retention, deletion, and tabletop gates. Defensive evaluation (`justai-defensive-evaluation-v1`) requires written consent and bounded sandboxes. Distributed defensive compute requires all preceding gates plus independent review and incident exercises.

No later phase may turn local replay, green tests, or signed artifacts into scientific proof, host resistance, alignment proof, production readiness, or political authority.
