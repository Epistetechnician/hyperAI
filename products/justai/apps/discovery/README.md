# Discovery application

State slice: `justai-discovery-v1`.

`src/loop.py` is a deterministic, proposal-only orchestration surface. It records algorithmic proposals, locked-budget alternatives, falsifiable intuition, dissent, accepted validation through either external-independent or bounded local-quorum evidence, promotion/Unknown/quarantine, and separate efficiency dimensions. Local quorum is capped at `local-replay` and does not select authorities or establish independent review. It does not execute models.
